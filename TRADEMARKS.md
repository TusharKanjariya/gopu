# The Gopu name and mascot

Gopu's code is open source under the [Apache-2.0 licence](LICENSE). The licence covers the code only. It doesn't
cover the Gopu name, the elephant mascot, the logo or the app icons (Apache-2.0 section 6 says the same).

- **You may** use the name to talk about Gopu, link to it, or say your project works with it.
- **You may not** use the name, mascot or logo for your own app, fork or service, or in a way that suggests it's the
  official Gopu. If you ship a fork, give it its own name and icon.

Unsure? Open an issue and ask.
