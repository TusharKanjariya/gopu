# Reporting a security problem

Gopu reads what's on your screen, so security problems matter. Please don't open a public issue for one.

Report it privately instead: go to the repository's **Security** tab, then **Report a vulnerability**. Include what
you found, how to reproduce it and the Gopu version (Settings → About). You'll get a reply within a week.

Fixes ship as a new release, which installed copies offer through their update check.
