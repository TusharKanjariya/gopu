# Contributing to Gopu

Bug reports, ideas and pull requests are welcome.

- **Bugs and ideas:** open an issue. For security problems, follow [SECURITY.md](SECURITY.md) instead.
- **Pull requests:** keep each one to a single change, and run `cargo test` before sending it.
- **Sign the CLA once.** Your first pull request gets a comment from the CLA check; reply with the sentence it asks
  for. The [Contributor Licence Agreement](CLA.md) lets the project's owner relicense or transfer Gopu with your work
  in it. You keep the copyright.
- **The name and mascot** are reserved; see [TRADEMARKS.md](TRADEMARKS.md).
